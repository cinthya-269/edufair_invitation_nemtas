EDU FAIR & CAREER DAY 2026 - WEBSITE UNDANGAN

Isi folder:
- index.html   : halaman undangan dengan surat pembuka dan personalisasi nama
- style.css    : desain biru dan tampilan responsif
- script.js    : membaca parameter URL dan interaksi surat/menu
- admin.html   : halaman admin untuk mengunggah CSV
- admin.js     : membaca CSV dan membuat tautan pesan WhatsApp
- data-tamu.csv: data tamu yang diberikan

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Simpan semua file dalam satu folder.
3. Buka folder di VS Code.
4. Jalankan index.html menggunakan Live Server (disarankan).
5. Buka admin.html, pilih data-tamu.csv, lalu klik Baca Data CSV.
6. Klik Kirim via WhatsApp pada baris tamu. WhatsApp akan terbuka dengan pesan dan tautan personal.

index.html?to=Universitas+Indonesia&kategori=Universitas
